# MCP Voice Soundboard

Text-to-speech MCP server for AI agents.

## Key Features

- **MCP Native** — stdio transport, works with Claude Desktop, Cursor, and any MCP client
- **48 Voices, 9 Languages** — English, Japanese, Mandarin, Spanish, French, Hindi, Italian, Portuguese
- **5 Tools** — voice_speak, voice_dialogue, voice_status, voice_interrupt, voice_inner_monologue
- **Emotion Spans** — 8 emotions via inline markup
- **SSML-lite & SFX Tags** — Break, emphasis, prosody, plus inline sound effects
- **Guardrails** — Rate limiting, concurrency control, timeouts, path traversal protection

## Install / Quick Start

```bash
npx @mcptoolshop/voice-soundboard-mcp
```
